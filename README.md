# pouwchain — дипломний проєкт

**Блокчейн-протокол з консенсусом для розподіленого навчання нейронних мереж.**
Бакалаврська кваліфікаційна робота, спеціальність 122, кафедра систем штучного інтелекту,
НУ «Львівська політехніка». Захист — червень 2027.

Вузли мережі замість перебору хешів виконують кроки навчання нейронної моделі, а мережа перевіряє
достовірність цієї роботи. Дослідницька частина — порівняння механізмів верифікації за часткою
виявлених атак і накладними витратами.

## Стан

Готово: контракт між C++ і Python (`docs/contract.md`), канонічний хеш ваг і заголовок блоку (`worker/canonical.py`).

Головна контрольна точка: **1 листопада 2026** — три вузли, навчання на MNIST, механізм верифікації B,
одна атака і перші цифри.

## Структура, якою вона стане

```
node/      C++: блок, ланцюг, валідація, P2P по TCP
worker/    Python: навчання, верифікація, атаки
sim/       Python: симулятор раундів без мережі
experiments/  конфіги, CSV з результатами, графіки
store/     ваги за хешем (у git не потрапляє)
docs/      план, рішення, дослідження, контракт
```
