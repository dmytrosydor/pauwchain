# Арена атак

Свою стратегію обману можна написати одним файлом і перевірити, чи пройде вона механізми A, B, R, C, D.

```sh
.venv/bin/python -m sim.arena --trials 3                     # усі стратегії з arena/strategies/
.venv/bin/python -m sim.arena --validators 3 --q 2 --alpha 0.05
```

Шаблон — `arena/strategies/_template.py` (файли з `_` арена пропускає). Стратегія отримує `ctx`:

| Що | Значення |
|---|---|
| `ctx.w_start`, `ctx.m`, `ctx.k`, `ctx.K`, `ctx.seed` | стартові ваги, кількість переходів, кроки в переході й у блоці, seed порядку даних |
| `ctx.verifier` | параметри перевірки: `q`, `alpha`, `residual_tau`, `validators` — атакувальник їх знає |
| `ctx.honest(state, j, steps=None)` | чесні кроки переходу j |
| `ctx.poisoned(state, j, p=1.0, lr_scale=1.0)` | перехід j на зіпсованих мітках |
| `ctx.noise_like(state, scale)` | гаусів шум тієї ж форми |
| `ctx.rng` | генератор випадкових чисел стратегії |

Арена рахує кроки навчання через `ctx` (стовпець «робота», частка від K) і шкоду — падіння точності
порівняно з чесним блоком. Табло: частка блоків, що пройшли кожен механізм, з 95 % інтервалом Вільсона.

Код стратегій виконується в процесі арени: запускайте лише стратегії, яким довіряєте.
